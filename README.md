# Live Processing Black Hole

> An interactive 3D black hole visualization built from scratch using Three.js, Vite, JavaScript and WebGL concepts.


##  About the Project

**Live Processing Black Hole** is an interactive browser-based visualization of a black hole and its surrounding accretion disk.

The main goal of this project was to understand how real-time 3D graphics can be created and controlled using JavaScript.

Instead of using a pre-rendered animation or video, the black hole is rendered **live in the browser**.

The scene responds to the user's cursor movement, allowing the camera and black hole perspective to move dynamically across different directions and angles.

The project was developed as a **2-day learning and implementation project**, with each day focused on a different stage of development.
